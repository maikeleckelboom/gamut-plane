## Budget failure evidence

The real approximator splits signed transfer transitions and zero, then bisects against the scalar second-derivative certificate. It permits at most 24 bisection levels and 16,384 emitted points. `RGB_CURVE_ERROR` stays `1e-5` encoded units; geometric coincidence stays `1e-12` linear units; Reference slice compatibility stays `1e-7` encoded units. SVG serialization adds at most `5e-6` screen units.

The new render test supplies deterministic extreme cube vertices at the existing internal conversion seam. A zero-based `1e20` varying-coordinate extent exhausts depth before the point ceiling. A positive-offset `1e12` extent fills the point ceiling. The actual intersection, transfer, certificate, recursion and limits run unchanged. Both return exactly `{ kind: "value-unavailable", reason: "approximation-budget" }`, omit a rendered path, retain independent interval/Reference/editing availability and preserve authored snapshot/exact results. This proves defensive bounded behavior; it does not claim that ordinary built-in RGB cubes exhaust the budget. No public test-only knobs, duplicated approximator or probabilistic search is introduced.

## Focused test-debt decisions

The previous two-Area tangent test used production linear conversion to choose its extrema. The stronger six-Area matrix already chooses both extrema through independent encoded conversion and checks coincidence, narrow sections and beyond-extrema emptiness. Open SVG assertions now live there; the weaker duplicate is removed.

The four focused white-channel cases duplicated the sibling/endpoint matrix. Their `[1,1,0.5]` fixture and twelve-decimal endpoint guarantee now live in that matrix alongside `[1,1,1]`, across both encodings. The browser's closed P3 white/line sentinel remains. No independent numerical oracle, framework/browser sentinel, tolerance or screenshot was removed or weakened.

## Remaining acceptance boundaries

Pinned Chromium and automated accessibility checks are the browser evidence. Physical touch/pen devices, real wide-gamut displays, manual screen readers and a permanent Firefox/WebKit matrix remain unverified. Existing transformed/capture/physical-blur edge-policy questions in [plane controller decomposition](plane-controller-decomposition.md) are not closed by this RGB increment. Sampled Reference compatibility remains conditional by design; incompatible endpoints are not repaired or mapped. Canvas is client-only.

Future Views, a classic picker, zoom/pan/Fit, further spaces/adapters, public headless APIs and mapping UI remain separate work. This candidate does not merge main, tag, publish or deploy.
