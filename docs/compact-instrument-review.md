## Compatibility decisions

The ordinary interface has no Edit / Inspect control. `editorId: null` remains a valid host-selected observation state, including controlled rejection and read-only use. It retains observed coordinates, alpha and requested boundaries without constructing an editor or reauthoring the color. Choosing Coordinates requests the preferred admitted editor, including from the same observed representation. Choosing the same representation while already editing preserves an explicit RGB Area.

The native control anatomy intentionally changes from three ranges to one range plus three numeric inputs. RGB visual and keyboard order becomes fixed-first: Blue then Red/Green for R/G, Green then Red/Blue for R/B, Red then Green/Blue for G/B. Representation tuple order, scalar operations, finite extended values, alpha and untouched channels retain their previous contracts. Host assertions that query mode radios or the removed ranges need updating.

Numeric cards retain Enter/change/blur completion, Escape cancellation, native stepping, controlled acceptance/rejection and draft reconciliation. Numeric bounds remain separate from rail limits and color validity. Missing Hue stays visibly unset until explicitly authored; display precision does not round untouched authored values. OKLab counterpart-dependent disc bounds and unavailable recovery remain intact.

## Final refinement and acceptance

The accepted interaction model and composition are retained. This pass changes only shared presentation, the decorative disclosure markup in both adapters, the forced-colors focus expectation, acceptance tests, reviewed images and this documentation.

Hue now focuses the complete value/unit wrapper with a four-pixel inset around the nonshrinking degree symbol. A numeric card has one outer focus ring, with no inner input outline. Native input borders are removed with equivalent padding, preserving normal content geometry while avoiding a second system focus box in forced colors. Gamut references has a subtle decorative layers icon and a semibold foreground label. The ordinary disclosure stays compact; enlarged text can move the exceptional cue to its own line.

The expanded popup matrix found a genuine 30px horizontal overflow at 320px/200% text in Paused and unavailable states. Boundary labels now wrap their Paused cue within the available width.
